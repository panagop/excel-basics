Μάθημα 13 · Μακροεντολές: σύντομη εισαγωγή

Εγγραφή ενεργειών, δικές σας συναρτήσεις και αυτοματοποίηση της Αναζήτησης στόχου

Σε αυτό το μάθημα θα μάθετε να

  • καταγράφετε και να εκτελείτε μια μακροεντολή·
  • βλέπετε και να διορθώνετε τον κώδικα VBA που δημιουργείται·
  • γράφετε δικές σας συναρτήσεις, π.χ. =BAR_AREA(4;16)·
  • αυτοματοποιείτε μια επαναλαμβανόμενη εργασία με έναν βρόχο·
  • αναγνωρίζετε τους κινδύνους ασφαλείας των μακροεντολών.
Το μάθημα είναι μια πρώτη γνωριμία: ο στόχος είναι να ξέρετε τι μπορούν να κάνουν οι μακροεντολές και πώς ξεκινάτε – όχι να μάθετε προγραμματισμό. Αυτό θα γίνει σε μαθήματα προγραμματισμού.

1. Τι είναι μια μακροεντολή

Μια μακροεντολή (macro) είναι μια σειρά ενεργειών που το Excel εκτελεί αυτόματα. Γράφεται στη γλώσσα VBA (Visual Basic for Applications), αλλά δεν χρειάζεται να ξέρετε VBA για να φτιάξετε την πρώτη σας: το Excel μπορεί να καταγράψει ό,τι κάνετε με το ποντίκι και το πληκτρολόγιο και να το μετατρέψει σε κώδικα. Χρήσιμες για:

  • εργασίες που επαναλαμβάνετε συχνά (μορφοποίηση πινάκων, εκτύπωση, εξαγωγή)·
  • δικές σας συναρτήσεις για τύπους που χρησιμοποιείτε συνέχεια·
  • διαδικασίες που οι τύποι δεν κάνουν μόνοι τους, π.χ. να ξανατρέχει η Αναζήτηση στόχου.

2. Η καρτέλα Προγραμματιστής

Τα εργαλεία βρίσκονται στην καρτέλα Προγραμματιστής (Developer), που είναι κρυφή αρχικά: Αρχείο → Επιλογές → Προσαρμογή κορδέλας (Customize Ribbon) → τσεκάρετε Προγραμματιστής στη δεξιά λίστα → OK.

3. Εγγραφή μακροεντολής: μορφοποίηση πίνακα

Στο φύλλο Μορφοποίηση του αρχείου υπάρχουν δύο αμορφοποίητοι πίνακες αποτελεσμάτων. Θα μορφοποιήσουμε τον πρώτο καταγράφοντας τις ενέργειές μας, και μετά θα εφαρμόσουμε την ίδια μορφοποίηση στον δεύτερο με ένα κλικ.

  1. Επιλέξτε τον πρώτο πίνακα (A5:E9).
  2. Προγραμματιστής → Εγγραφή μακροεντολής (Record Macro). Όνομα: FormatTable (χωρίς κενά), αποθήκευση σε Αυτό το βιβλίο εργασίας. OK – από εδώ και πέρα ό,τι κάνετε καταγράφεται.
  3. Δώστε περιγράμματα και μορφή αριθμού 0,00 σε όλη την επιλογή· μετά επιλέξτε την πρώτη γραμμή και κάντε τη έντονη, με πράσινο γέμισμα και λευκά γράμματα.
  4. Προγραμματιστής → Διακοπή εγγραφής (Stop Recording).
  5. Επιλέξτε τον δεύτερο πίνακα (A12:E15) και Προγραμματιστής → Μακροεντολές (Alt+F8) → FormatTable → Εκτέλεση.
Απόλυτες ή σχετικές θέσεις; Αν κατά την εγγραφή κάνετε κλικ σε συγκεκριμένα κελιά, ο καταγραφέας γράφει απόλυτες διευθύνσεις (Range("A5:E5").Select) και η μακροεντολή θα μορφοποιεί πάντα τα ίδια κελιά. Για μακροεντολή που δουλεύει «εκεί που βρίσκομαι», ενεργοποιήστε Χρήση σχετικών αναφορών (Use Relative References) πριν την εγγραφή – θυμίζει το Μάθημα 3!

4. Ο κώδικας VBA

Alt+F11 ανοίγει τον επεξεργαστή VBA. Η καταγεγραμμένη μακροεντολή βρίσκεται στο Modules → Module1. Ο καταγραφέας γράφει πολύ περισσότερο κώδικα απ’ όσο χρειάζεται· μια «καθαρή» εκδοχή της ίδιας μακροεντολής, που δουλεύει σε οποιαδήποτε επιλογή: 

Sub FormatTable()
' Μορφοποιεί την επιλεγμένη περιοχή: περιγράμματα, 2 δεκαδικά, επικεφαλίδα
    With Selection
        .Borders.LineStyle = xlContinuous
        .NumberFormat = "0.00"
        .Columns.AutoFit
    End With
    With Selection.Rows(1)
        .Font.Bold = True
        .Font.Color = vbWhite
        .Interior.Color = RGB(33, 115, 70)
        .HorizontalAlignment = xlCenter
    End With
End Sub

Ακόμη κι αν δεν ξέρετε VBA, ο κώδικας διαβάζεται: «για την επιλογή (Selection), βάλε περιγράμματα, μορφή 0.00, αυτόματο πλάτος στηλών· για την πρώτη γραμμή, έντονα λευκά γράμματα σε πράσινο φόντο». Οι γραμμές με ' είναι σχόλια.

Η VBA είναι «αγγλική». Μέσα στον κώδικα η υποδιαστολή είναι πάντα τελεία και οι κωδικοί μορφής γράφονται με τελεία ("0.00"), όποιες κι αν είναι οι τοπικές ρυθμίσεις του υπολογιστή (οδηγός τοπικών ρυθμίσεων).

Κουμπί για τη μακροεντολή

Προγραμματιστής → Εισαγωγή → Κουμπί (στοιχείο ελέγχου φόρμας) (Insert → Button, Form Control): σχεδιάστε το κουμπί στο φύλλο, και στο παράθυρο που ανοίγει διαλέξτε τη μακροεντολή (Αντιστοίχιση μακροεντολής, Assign Macro). Δεξί κλικ στο κουμπί για να αλλάξετε το κείμενό του.

5. Δικές σας συναρτήσεις

Η VBA επιτρέπει να γράψετε συναρτήσεις που χρησιμοποιούνται στα κελιά ακριβώς όπως οι ενσωματωμένες (UDF – User Defined Functions). Στον επεξεργαστή VBA: Insert → Module και επικολλήστε: 

Function BAR_AREA(n As Double, phi As Double) As Double
' Εμβαδόν n ράβδων διαμέτρου phi (mm), σε cm²
    BAR_AREA = n * WorksheetFunction.Pi() * phi ^ 2 / 4 / 100
End Function

Function FCD_DESIGN(fck As Double, Optional acc As Double = 0.85) As Double
' Αντοχή σχεδιασμού σκυροδέματος f_cd = acc·fck/γc, με γc = 1.5 (MPa)
    FCD_DESIGN = acc * fck / 1.5
End Function

Τώρα, σε οποιοδήποτε κελί του βιβλίου εργασίας:

ΤύποςΑποτέλεσμα
=BAR_AREA(4;16)8,04 (cm², 4Φ16)
=FCD_DESIGN(25)14,17 (MPa, με αcc = 0,85 ως προεπιλογή)
=FCD_DESIGN(25;1)16,67 (MPa, με αcc = 1,0)

Παρατηρήστε τη διαφορά: στον κώδικα VBA τα ορίσματα χωρίζονται με , και η υποδιαστολή είναι .· στο κελί, με ελληνικές ρυθμίσεις, γράφετε ; και , όπως σε κάθε συνάρτηση. Ένας τύπος που χρησιμοποιείτε συχνά, γραμμένος μία φορά ως συνάρτηση, μειώνει τα λάθη και κάνει τα φύλλα πιο ευανάγνωστα – όπως τα ονόματα κελιών του Μαθήματος 3.

6. Βρόχος: Αναζήτηση στόχου για πολλές διατομές

Στο Μάθημα 10 είδαμε ότι η Αναζήτηση στόχου δεν ενημερώνεται όταν αλλάζουν τα δεδομένα, και ότι τρέχει για ένα κελί τη φορά. Το φύλλο Αναζήτηση του αρχείου έχει τρεις διατομές σε στήλες C, D, E (4Φ20, 6Φ20, 6Φ25), με το x στη γραμμή 17 και την ισορροπία Fc − Fs στη γραμμή 23. Μια μακροεντολή με βρόχο τις λύνει όλες: 

Sub SolveAll()
' Για τις στήλες C (3) έως E (5): F_c - F_s (γραμμή 23) = 0, αλλάζοντας το x (γραμμή 17)
    Dim c As Integer
    For c = 3 To 5
        Cells(17, c).Value = 0.1              ' αρχική τιμή του x
        Cells(23, c).GoalSeek Goal:=0, ChangingCell:=Cells(17, c)
    Next c
End Sub

Το Cells(γραμμή, στήλη) δείχνει ένα κελί με αριθμούς αντί για γράμματα, ώστε ο βρόχος For c = 3 To 5 να περνά από τις στήλες C, D, E. Η γραμμή GoalSeek κάνει ακριβώς ό,τι και το παράθυρο της Αναζήτησης στόχου. Βάλτε την σε ένα κουμπί «Επίλυση» στο φύλλο: αλλάζετε ένα δεδομένο, πατάτε το κουμπί, και όλες οι διατομές λύνονται ξανά. Αναμενόμενα (αcc = 0,85): x = 0,1607 / 0,2410 / 0,3491 m, MRd = 265,4 / 371,7 / 487,0 kNm – και ο χάλυβας της τρίτης διατομής δεν διαρρέει.

7. Αποθήκευση και ασφάλεια

  • Αποθήκευση: ένα αρχείο με μακροεντολές πρέπει να αποθηκευτεί ως Βιβλίο εργασίας του Excel με δυνατότητα μακροεντολών (.xlsm). Αν το αποθηκεύσετε ως .xlsx, ο κώδικας χάνεται.
  • Κίνδυνος: μια μακροεντολή μπορεί να κάνει σχεδόν οτιδήποτε στον υπολογιστή σας – και μέσω αρχείων με μακροεντολές διαδίδεται κακόβουλο λογισμικό. Γι’ αυτό το Excel τις απενεργοποιεί από προεπιλογή και εμφανίζει μια κίτρινη γραμμή Ενεργοποίηση περιεχομένου (Enable Content).
  • Αρχεία από το διαδίκτυο ή από email: οι μακροεντολές τους μπλοκάρονται εντελώς, με κόκκινη γραμμή προειδοποίησης. Αν εμπιστεύεστε απόλυτα την πηγή: δεξί κλικ στο αρχείο → Ιδιότητες → τσεκ Κατάργηση αποκλεισμού (Unblock).
  • Κανόνας: ποτέ μην ενεργοποιείτε μακροεντολές σε αρχείο που δεν ξέρετε από πού προέρχεται.

Γι’ αυτό το αρχείο του μαθήματος είναι απλό .xlsx χωρίς κώδικα: τον κώδικα τον αντιγράφετε εσείς από αυτή τη σελίδα, άρα ξέρετε ακριβώς τι εκτελείται.

8. Και μετά;

Η VBA είναι μια ολοκληρωμένη γλώσσα προγραμματισμού, με μεταβλητές, συνθήκες, βρόχους και φόρμες διαλόγου. Πολλά «εργαλεία» μηχανικών σε Excel (π.χ. φύλλα διαστασιολόγησης) είναι γραμμένα έτσι. Για πιο σύνθετους υπολογισμούς, οι μηχανικοί στρέφονται όλο και περισσότερο στην Python – που σε ορισμένες εκδόσεις του Microsoft 365 μπορεί να γραφτεί και απευθείας σε κελιά του Excel. Οι έννοιες που μάθατε εδώ (κελιά, αναφορές, συναρτήσεις, βρόχοι) είναι ίδιες σε όλα.

9. Δοκιμάστε μόνοι σας

⬇ Λήψη 13-macros.xlsx

  1. Ενεργοποιήστε την καρτέλα Προγραμματιστής.
  2. Φύλλο Μορφοποίηση: καταγράψτε τη μακροεντολή FormatTable στον πρώτο πίνακα και εκτελέστε τη στον δεύτερο. Δείτε τον κώδικα με Alt+F11.
  3. Φύλλο Συναρτήσεις: προσθέστε τις BAR_AREA και FCD_DESIGN σε ένα Module και συμπληρώστε τα κίτρινα κελιά.
  4. Φύλλο Αναζήτηση: προσθέστε τη SolveAll, φτιάξτε ένα κουμπί «Επίλυση» και πατήστε το. Αλλάξτε το fck σε 30 και ξαναπατήστε.
  5. Αποθηκεύστε ως .xlsm, κλείστε και ανοίξτε ξανά το αρχείο: τι εμφανίζεται;

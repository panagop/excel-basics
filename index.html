Excel for Civil Engineers

An introduction to spreadsheets for first-semester students

Spreadsheets are one of the everyday tools of a civil engineer: quantity take-offs, cost estimates, laboratory measurements, design checks and quick calculations are all done in Excel. These lessons start from the very beginning and build up, step by step, to more advanced topics.

How to use these lessons

  1. Read each lesson in order – every lesson uses what you learned in the previous ones.
  2. Download the example file (.xlsx) of the lesson and open it in Excel.
  3. Study the Example sheet, then complete the Exercise sheet yourself.

Use the menu on the left (or the ☰ button on a phone) to move between lessons.
